# work
list of AI using work style

## Skills

Reusable workflows live in `skills/<name>/SKILL.md`. Follow [AGENTS.md](AGENTS.md) when adding or updating them.

| Skill | Purpose |
| --- | --- |
| [feature](skills/feature/SKILL.md) | Add, modify, or remove functionality while checking affected workflows. |
| [test](skills/test/SKILL.md) | Add focused tests for existing behavior and regressions. |
| [pr](skills/pr/SKILL.md) | Prepare a reviewable PR title and description; publish when requested. |
| [docs](skills/docs/SKILL.md) | Align repository documentation and examples with intended behavior. |
| [perf](skills/perf/SKILL.md) | Diagnose and improve runtime performance using measurements. |
| [handoff](skills/handoff/SKILL.md) | Capture verified context and next actions for continuing work. |
| [playwright](skills/playwright/SKILL.md) | Inspect browser workflows and capture reproducible UI evidence. |
| [gh-fix-ci](skills/gh-fix-ci/SKILL.md) | Diagnose and repair failing GitHub Actions checks. |
| [gh-address-comments](skills/gh-address-comments/SKILL.md) | Evaluate PR review feedback and implement scoped corrections. |

These folders are source files; adding them here does not install them into a user-level skill directory. The browser and GitHub workflows are local adaptations for this repository, not copies of upstream helper scripts.
