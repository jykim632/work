# Handoff — 인수인계

이 문서는 [SKILL.md](SKILL.md)의 한글 번역본입니다. 스킬 실행 지침의 기준은 영문 원문입니다.

**설명:** 다른 세션이나 협업자가 작업을 이어갈 수 있도록 현재 작업, 결정, 검증, 미해결 문제, 다음 행동을 근거와 함께 정리한 인수인계 메모를 작성합니다.

다음 세션에서 같은 내용을 다시 조사하지 않고 작업을 이어갈 수 있도록 충분히 검증된 맥락을 기록합니다.

## 작업 방식

- 작성 위치, 개인정보 보호, 외부 작업에 관한 프로젝트 지침과 기존 사용자 선호를 따릅니다.
- 사용 가능한 대화 맥락, Git 상태, 브랜치와 worktree, 관련 diff, 기록된 검증을 검토합니다. 관련 없는 변경을 현재 작업의 결과로 설명하지 않습니다.
- 요청한 위치와 형식을 사용합니다. 지정하지 않았다면 임의로 외부 서비스를 선택하거나 저장소 파일을 만들지 말고 대화에서 메모를 제공합니다.

## 이어가기 메모 작성

- 목표와 합의한 범위, 완료한 작업, 남은 작업을 밝힙니다. 구현 완료 여부와 검증 및 게시 상태를 구분합니다.
- 결정과 구체적인 이유, 관련 제약, 작업을 이어가는 데 필요한 파일·이슈·산출물 참조를 포함합니다. 대화 전체나 diff 전체를 복사하지 않습니다.
- 실제 수행한 확인과 결과를 기록합니다. 확인된 사실, 가설, 대기 중인 작업, 진행을 막는 요인을 구분합니다.
- 관련이 있다면 현재 브랜치와 worktree, 아직 커밋하지 않은 중요한 작업을 명시합니다. 로컬 파일이나 임시 경로를 다른 컴퓨터에서도 사용할 수 있다고 주장하지 않습니다.
- 부족한 정보나 필요한 승인을 포함하여, 다음에 수행할 유용한 행동을 의존 순서대로 제시합니다. 메모가 새로운 권한을 부여하는 것처럼 표현하지 않습니다.
- 자격 증명, 비공개 페이로드, 불필요한 개인정보를 제외합니다. 메모를 다른 사람에게 보내거나 게시하려면 명시적인 승인이 필요합니다.
