# Docs — 문서

이 문서는 [SKILL.md](SKILL.md)의 한글 번역본입니다. 스킬 실행 지침의 기준은 영문 원문입니다.

**설명:** 의도한 동작, 설정, 공개 계약에 맞도록 저장소 문서와 실행 가능한 예제를 작성하거나 갱신합니다.

저장소 문서가 대상 독자에게 정확하고 유용하도록 유지합니다.

## 작업 방식

- 도구, Git 작업 방식, 코딩 규칙, 승인에 관한 프로젝트 지침과 기존 사용자 선호를 따릅니다.
- 관련 README, 안내 문서, 설정 예제, 구현, 테스트, 공개 호출부를 찾습니다. 기존 문서 구조와 언어를 따릅니다.
- 독자가 수행하려는 작업과 의도한 계약을 파악합니다. 문서와 구현이 다르면 현재 구현을 그대로 문서화하지 말고 어느 쪽이 맞는지 판단합니다.

## 작성과 검증

- 요청의 영향을 받는 최소한의 일관된 문서 묶음을 갱신합니다. 여러 문서에서 공유하는 사실은 한곳에서 관리하고 적절히 링크합니다.
- 독자에게 필요한 수준으로 사전 조건, 실제 명령, 예상 결과, 관련 실패 처리 방법을 설명합니다. 지원되는 호환성과 설정 경로를 유지합니다.
- 외부 기술에 관한 설명은 최신의 신뢰할 수 있는 공식 자료와 대조합니다. 존재하지 않는 플래그, 기본값, 환경 변수, 플랫폼 기능을 만들어내지 않습니다.
- 자격 증명과 비공개 값에는 플레이스홀더를 사용합니다. 예제를 실행하기 전에 의도하지 않은 영향을 확인합니다. 실행이 외부 상태를 변경한다면 문법을 검증하거나 격리된 환경을 사용합니다.
- 사용 가능한 문서 검사를 실행하고, 가능한 경우 변경한 로컬 링크와 예제를 확인합니다. 자동 생성 문서는 기존 원본과 생성 도구를 통해 갱신합니다.
- 수정한 내용, 이를 뒷받침하는 확인, 검증하지 못한 예제나 설명을 보고합니다. 문서 작업 중 발견한 제품 결함은 보고하되, 알리지 않고 구현 변경으로 범위를 확대하지 않습니다.
